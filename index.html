PMI 官方公開範例

這個分頁與「仿真題庫」分開。這裡只整理 PMI 官方網站已公開的 PMP sample questions、2026 Exam Content Outline 題型說明與官方備考入口。

重要：正式 PMP 考場中的未公開題目屬於機密考試內容。本工具不收錄外洩題、考生回憶重建題或聲稱是「真題」但無法確認授權來源的題庫。

官方 Sample Question 1｜變更控制

官方公開題意摘要：專案接近重大發布，關鍵利害關係人提出可能提升客戶滿意度、但可能延後發布的重要變更。題目問 PM「首先」應做什麼。

官方答案核心：先評估變更影響，再遵循既定變更控制流程。
你要記：看到 Predictive / 已有核准計畫 / 重大變更時，不要直接做，也不要直接拒絕；先 impact analysis → change control。

來源：PMI PMP Certification 官方頁面的 Sample Exam Questions。為避免複製官方受版權保護內容，本工具只保留題意摘要與學習解析。

官方 Sample Question 2｜利害關係人越權指示

官方公開題意摘要：一位有影響力的利害關係人反覆直接指揮團隊，內容與已核准計畫衝突，導致優先順序混亂與進度下滑。題目問 PM 下一步應如何處理。

學習核心：不要因對方有權力就默默改計畫，也不要讓團隊自行承受衝突；應回到治理、角色權責、核准計畫與正式溝通機制處理。
你要記：有影響力 ≠ 可以繞過 governance。PMP 題目常測你能否在尊重利害關係人的同時，維持正式決策流程。

來源：PMI PMP Certification 官方頁面的 Sample Exam Questions。此處為摘要與解析，不重製完整官方題目。

官方 Sample Question 3｜供應商延遲風險

官方公開題意摘要：測試期間，關鍵供應商通知必要零組件可能延遲約兩週；專案期限緊迫且已沒有時程預備，贊助人詢問上市日期是否仍安全。題目問 PM「首先」應做什麼。

官方答案核心：先評估延遲對專案的影響，並與團隊評估可行的應對方案。
你要記：收到風險／問題資訊後，不要先保證期限、立刻壓縮時程或直接把決策丟給 sponsor；先做 impact analysis → response options → 再以事實溝通與決策。

來源：PMI PMP Certification 官方頁面的 Sample Exam Questions。此處為題意摘要與學習解析，不重製完整官方題目。

2026 官方題型變化

題型官方說明重點
Multiple-choice single response單選題，一個正確答案。
Multiple-response複選題，可能有多個正確答案。
Graphic-based question2026 ECO 明確列出的新題型之一，需要解讀圖表、圖形、圖像或視覺資訊後作答。
Point and Click在圖片指定區域點選正確位置；僅部分考試形式支援。
Case study / hands-on style新版官方考試資訊也提到可能包含案例與實務操作型內容。

建議：不要只練「四選一文字題」。正式備考後期應加入圖表判讀、複選題與長情境題。

如何使用這個分頁

  1. 先在 PMI 官網做官方 Sample Questions。
  2. 回到這裡對照「官方答案核心」與 PMI Mindset。
  3. 再到「刷題練習」用相同主題大量練習。
  4. 若遇到網路上聲稱「PMP 真題／考生回憶題」，不要把它當成可靠官方來源。

PMP 情境題常用 Mindset

看到什麼情境優先思考
衝突／抱怨先理解事實與根因 → 促進合作 → 必要時才升級。
成員能力或績效下降先一對一了解原因 → coaching / support → 再談正式處置。
Agile 團隊被阻塞僕人式領導：移除 impediment、賦能團隊，而非代替團隊工作。
Predictive 新需求／大變更先記錄與 impact analysis → 依 change control 核准 → 再更新 baseline / 執行。
新風險識別 → 分析 → 規劃 response → assign owner → monitor。
風險已發生成為 issue；執行已規劃 response，更新 issue / risk 資訊。
反覆缺陷Root cause + prevention，不要只靠 inspection。
市場／策略改變重新驗證 business case、價值與優先順序；避免沉沒成本偏誤。
Agile 新需求通常先進 Product Backlog，由 PO 依價值排序，不隨意破壞目前迭代。
合規／資安／倫理不可為趕進度跳過 mandatory governance。
AI 使用先資料治理、隱私、安全、倫理、政策與合規，再談擴大使用。
「完成很多」但成果差Output ≠ Outcome；回到採用率、效益、商業價值與使用者成果。
計算題速記

SPI = EV / PV；CPI = EV / AC；EMV = Probability × Impact；PERT = (O + 4M + P) / 6；溝通管道 = n(n−1)/2。實際情境題通常更重視你如何解讀數字並做決策。
